# Decision Tree Regression From Scratch

## Context

The project requires a Decision Tree Regression model implemented from scratch for the Product Sales Prediction task.

## Task

Design a Decision Tree Regression implementation from scratch.

## Required Analysis

Explain:

1. Node data structure.
2. Best split search.
3. Threshold selection.
4. Weighted MSE calculation.
5. Stopping criteria.
6. Leaf prediction.
7. `max_depth`.
8. `min_samples_split`.

## Constraints

- Do not use `sklearn.DecisionTreeRegressor`.
- Prefer a simple and understandable implementation.
- `max_depth` and `min_samples_split` should be treated as important hyperparameters.
- Explain the design before writing code.
- Identify important edge cases.
- The implementation must be testable.

## Expected Output

Provide:

1. Node data structure.
2. Pseudocode.
3. Best split procedure.
4. Weighted MSE calculation.
5. Stopping criteria.
6. Prediction procedure.
7. Hyperparameter checklist.
8. Edge cases.
