# Prompt 06 - Data Pipeline Tests

Perform a focused TV1 test audit. Verify automated tests cover the monthly grid, lag alignment, rolling temporal correctness, next-month target, target exclusion, chronological split, train-only preprocessing, aligned X schemas, finite matrices, unknown categories, and raw-data immutability. Do not add features. Add the smallest useful test only for uncovered dangerous behavior; fix a real bug if exposed and rerun all TV1 tests.

Report tests discovered/changed, command, passing/failing counts, bugs, and final status.

## Output language

Write all user-facing findings, reports, result summaries, and documentation updates in Vietnamese. Keep code, commands, filenames, column names, and identifiers in English.
