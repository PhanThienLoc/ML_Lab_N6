# Linear Regression From Scratch

## Context

The project requires a Linear Regression model implemented from scratch for the Product Sales Prediction task.

## Task

Design and explain a Linear Regression implementation using Gradient Descent.

## Required Analysis

Explain:

1. Linear Regression model.
2. Prediction function.
3. MSE loss function.
4. Gradient calculation.
5. Weight update.
6. Bias update.
7. Learning rate.
8. Stopping condition.

## Constraints

- Do not use `sklearn.LinearRegression`.
- NumPy may be used for numerical calculations.
- Explain the mathematical formulas before writing code.
- Write pseudocode before implementation.
- Separate the `fit()` and `predict()` methods.
- The implementation must be understandable and testable.

## Expected Output

Provide:

1. Mathematical formulas.
2. Explanation of each component.
3. Pseudocode.
4. Implementation checklist.
5. Unit testing checklist.
6. Common implementation errors.
